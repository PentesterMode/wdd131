Autism Awareness

Site and Domain Name

Site Name: Autism Awareness

Domain Name: autism-aware.org

Description: This name clearly communicates the platforms focus on autism and the awareness that it brings.

Site Purpose

The purpose of this site is to educate the general public about Autism Spectrum disorder,foster emphathy and meaningful inclusions.The website will focus on common autistic behaviours like stimming,sensory sensitivities and communication differences and advice on how the community can effectively support and accomodate individuals on the spectrum.

Target Audience and User Scenarios

Target Audience: Family members, teachers, coworkers and communitany members looking for accessible information on autism and practical guidance on inclusion

User Scenarios:

  • Why does an autistic person engage in repetitive behaviour and how do i respond posetively?
  • How can i adjust noisy or bright enviroments to help someone experiencing sensory overload?
  • What are effective ways of communicating with non-verbal or quiet individuals on the spectrum?

Color Palette and Typography

Color Paletee

  • Primary Color: #B6845C -Cinnamon, used for primary headings, accent blocks and some User Interface Elements.
  • Secondary Color: #B2644E -An earthy color for buttons, hover effects and borderlines.
  • Background Color: #EOD1B8 -Warm oatmeal background to support sensory friendly reading.
  • Text Color: #24160E -Deep Ebony for clear text that is soft on the eyes.

Typography

Font: Sans-Serif Lato for everything

Wireframes and Layout Structure

Mobile Layout View

On small screens,the header displays the site title alongside a hamburger menu and content blocks are stacked vertically for comforatable reading.

Desktop Layout View

On larger screens navigation links will stretch horizontally across the header and the content will switch to a multi-column CSS Grid layout
